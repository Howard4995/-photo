# 圖片審核系統 (Image Review System)

這是一個輕量級的評分系統，。無需安裝任何後端服務，直接透過瀏覽器開啟即可使用。

## 下載與安裝說明

- **原版網址下載**：建議您先從 [原始下載網址 (請填入網址)] 下載最新版本的程式。
- **自動降級使用 Dress-master**：**請注意**，如果您沒有或無法透過上述網址下載原版檔案，您可以直接使用 `Dress-master` 這個檔案（或資料夾）來作為預設來源運行本次圖片審核系統。

## 功能特色
- **視覺評分反饋機制**：針對不同評分（A、B、C、F）加入專專屬的動畫與特效，加強評分當下的回饋感！
- **批次載入**：支援選取多張圖片或直接匯入整個包含圖片的資料夾。
- **自動提取與切換**：評分後自動無縫切換到下一張圖片。
- **完整總結報告**：全數審核完畢後，自動彙整各評分等級的統計數據與詳細清單。
- **Cookie 進度恢復**：自動記錄審核進度，下次開啟可續接上次進度。

## 快捷鍵評分 (鍵盤操作)

為了提升審核效率，系統支援鍵盤快捷鍵進行評分（對應上方數字鍵或九宮格數字鍵）：

- 按下 `1` : 評分為 **A**
- 按下 `2` : 評分為 **B**
- 按下 `3` : 評分為 **C**
- 按下 `0` : 評分為 **F**
- 按下 `Backspace` : **復原上一張 (Undo)**

## 使用方法
1. 下載或克隆此專案。
2. 使用任何現代瀏覽器（Chrome, Edge, Firefox, Safari 等）直接開啟 `index.html` 檔案。
3. 點擊「選擇圖片或資料夾」載入您要審核的圖片。
4. 開始點擊介面上的按鈕或使用鍵盤數字鍵進行評分。
5. 審核完成後，查看總結報告。
